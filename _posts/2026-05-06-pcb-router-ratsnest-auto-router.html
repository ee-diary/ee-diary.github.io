PCB Router — Ratsnest & Auto-Router Visualizer

Design, test, and visualize PCB routing algorithms directly in your browser with the PCB Router — Ratsnest & Auto-Router Visualizer. This interactive web app helps electronics engineers, PCB designers, students, and hobbyists understand how PCB auto-routing works using real-time routing simulations, animated trace generation, and ratsnest visualization.

The tool provides a modern PCB routing playground where users can experiment with routing strategies, inspect trace paths, optimize PCB layouts, and visualize routing decisions step by step. Whether you are learning PCB design fundamentals or exploring routing algorithms such as Lee routing and Dijkstra pathfinding, this visualizer makes PCB routing easier to understand.
